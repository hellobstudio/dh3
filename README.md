# DiákH – hiányzáskövető (Android)

Kotlin + Jetpack Compose, SQLite. Külső Excel-könyvtár nélkül.

## APK készítése GitHubon
1. Hozz létre egy új GitHub repót, és töltsd fel a mappa teljes tartalmát (a rejtett `.github` mappát is).
2. Az **Actions** fülön lefut a "Build APK" (vagy indítsd kézzel: Run workflow).
3. A lefutott futás alján, az **Artifacts** között töltsd le a `DiakH-apk` csomagot – benne van az `app-debug.apk`.
4. Telepítés előtt engedélyezd a telefonon az ismeretlen forrásból történő telepítést.
